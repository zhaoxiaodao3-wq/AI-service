# 03 · 引用溯源与前端展示

## 做了什么

SSE `done` 事件现在携带 `citations`：

```json
{
  "doc_id": 9,
  "chunk_index": 0,
  "text": "苹果是红色的...",
  "filename": "知识库.txt"
}
```

前端 AI 消息下方展示引用 chip：`知识库.txt #1`。

## 为什么

用户需要知道“答案凭什么这么说”，引用让 RAG 可验证、可追溯。

## 原理

检索服务在返回 TopK 后，通过 `document_id` 查回文件名，组装 citations 传给 chat_service，最终放进 `done` 事件。

## 命令解释

```powershell
$body = '{"messages":[{"role":"user","content":"苹果是什么颜色？"}],"model":"glm-4-flash","use_rag":true}'
Invoke-RestMethod -Uri http://localhost:8000/api/chat/stream -Method Post -ContentType "application/json" -Body $body -Headers @{Authorization="Bearer $token"}
```

`done` 里会带 citations。

## 避坑

- 引用要带用户可见的文件名，只给 chunk_index 用户看不懂。
- `text` 截断展示，避免刷屏。
- 阶段 13 再做“点击引用跳转到文档原文”。
