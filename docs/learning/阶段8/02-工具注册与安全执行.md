# 02 · 工具注册与安全执行

## 做了什么

内置四个工具：

- `get_current_time`
- `calculator`（安全 AST 计算）
- `search_knowledge`（当前用户知识库检索）
- `list_documents`（当前用户文档列表）

## 为什么

工具不能散落在各处，需要统一的注册中心，让模型能“看到”工具、代码能“找到”工具。

## 原理

### 注册中心

```python
TOOLS = [Tool(name=..., description=..., parameters=..., handler=...)]

def list_tools():
    return [tool.to_openai() for tool in TOOLS]
```

### 安全计算

计算器用 AST 解析，只允许常量与基础运算符，不执行任意代码：

```python
_safe_eval(ast.parse(expr, mode="eval"))
```

## 命令解释

```powershell
cd backend
.\venv\Scripts\python.exe -c "import asyncio; from app.tools.registry import execute_tool; print(asyncio.run(execute_tool('calculator', {'expression':'10/4'}, None)))"
```

## 避坑

- 永远不要用 `eval()` 执行模型生成的表达式。
- 涉及用户数据的工具必须带 `user_id`，否则会越权。
- 工具返回值要限制长度。
