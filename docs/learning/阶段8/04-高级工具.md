# 04 · 高级工具（天气与汇率）

## 做了什么

新增两个免费实用工具：

- `get_weather`：按城市查询实时天气（wttr.in）。
- `convert_currency`：按实时汇率换算金额（open.er-api.com）。

## 为什么

这些工具无需 API Key、无需企业资质，直接可用，能让 Agent 回答“北京今天多少度”“100 美元是多少人民币”这类实时问题。

## 原理

### 天气

```text
GET https://wttr.in/<city>?format=j1
→ current_condition[0]：温度/体感/湿度/风速/描述
```

### 汇率

```text
GET https://open.er-api.com/v6/latest/<FROM>
→ rates[TO] → amount × rate
```

两个工具都用 `httpx.AsyncClient(timeout=8)`，失败返回友好提示。

## 命令解释

```powershell
$body = '{"messages":[{"role":"user","content":"北京今天多少度？"}],"model":"glm-4-flash","use_tools":true}'
Invoke-RestMethod -Uri http://localhost:8000/api/chat/stream -Method Post -ContentType "application/json" -Body $body -Headers @{Authorization="Bearer $token"}
```

## 避坑

- 城市名用 URL 编码，避免中文路径问题。
- 汇率接口可能因网络/源站策略不可用，工具必须降级不抛错。
- 免费接口有频次限制，生产可加缓存。
