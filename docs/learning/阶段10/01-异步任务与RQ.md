# 01 · 异步任务与 RQ

## 做了什么

文档上传改为异步：

```text
上传 → 保存临时文件 → 创建 DocumentTask(pending) → 入队 RQ → 立即返回

worker：解析 → 切片 → Embedding → Qdrant → PG chunks → completed
```

## 为什么

文档解析 + 向量化可能耗时几秒到几十秒，同步处理会卡住上传请求。用任务队列后，请求秒回，后台慢慢处理，前端轮询进度。

## 原理

### RQ

- Redis 作为任务队列存储。
- 后端 `Queue.enqueue(function, task_id)` 入队。
- worker 容器执行 `Worker([queue]).work()` 消费。

### DocumentTask

```text
status: pending → processing → completed / failed
error / file_path / created_at / updated_at
```

## 命令解释

```powershell
docker compose ps
```

应看到 `aigc-worker` 与 `aigc-redis`。

## 避坑

- worker 与 backend 必须共享上传目录卷，否则读不到临时文件。
- RQ 新版本 `Connection` 位置变化，用 `Queue(name, connection=...)` 最稳。
- worker 崩溃后任务仍在 Redis 队列，重启即可续跑。
