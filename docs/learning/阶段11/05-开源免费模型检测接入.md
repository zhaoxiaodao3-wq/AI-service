# 05 · 开源/免费模型检测接入

## 做了什么

把 Guard 做成可切换 Provider：

- `heuristic`：正则快速拦截，零成本
- `llm_judge`：用免费 GLM 复核“可疑但未命中正则”的输入
- `prompt_guard`：开源模型预留入口（ONNX + transformers）
- 模型下载脚本：`download_prompt_guard.py`（hf-mirror）

## 为什么

正则容易被绕过，但模型检测有成本。折中方案：正则先拦，模型只复核可疑内容，兼顾速度与准确率。

## 原理

```text
normalize → heuristic
  命中 → blocked
  未命中且 suspicious → llm_judge / prompt_guard 复核
  复核失败 → 回退 safe，不阻塞
```

## 命令解释

```powershell
docker exec -e PROMPT_GUARD_PROVIDER=llm_judge -e PROMPT_GUARD_JUDGE_ALWAYS=true aigc-backend python verify_guard.py
```

可看到返回 `(decision, 'llm_judge')`。

## 避坑

- `llm_judge` 每轮多一次模型调用，建议只对可疑内容复核。
- `prompt_guard` 需要先下载模型并设置 `PROMPT_GUARD_MODEL_DIR`，未配置自动回退。
- 模型/复核失败一律降级，不能影响正常聊天。
