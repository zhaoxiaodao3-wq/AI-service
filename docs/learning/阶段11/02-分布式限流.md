# 02 · 分布式限流

## 做了什么

聊天限流从单机内存升级为 Redis 分布式滑动窗口：

- 按 IP：默认 30 次/分
- 按用户：默认 60 次/分
- Redis 故障回退内存

## 原理

```text
ZSET key = rl:ip:{ip} / rl:user:{id}
score = 当前时间
zadd → zremrangebyscore(窗口外) → zcard > limit → 429
```

## 命令解释

```powershell
docker exec aigc-redis redis-cli --scan --pattern "rl:*"
```

## 避坑

- 用户维度要先解 Token。
- Redis 挂了不能把接口打挂，必须降级。
- ZSET 要设过期，防 key 膨胀。
