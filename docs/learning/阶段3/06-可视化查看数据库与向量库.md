# 06 · 可视化查看数据库与向量库

## 做了什么

新增两个可视化入口：

- **Adminer**：网页查看 PostgreSQL 表，地址 http://localhost:5050。
- **Qdrant Dashboard**：Qdrant 自带的网页界面，地址 http://localhost:6333/dashboard，不用额外装容器。

两者都随 `docker compose up -d` 一起启动。

## 为什么

看代码、看接口日志都只能看到“程序视角”，遇到“表里到底存了什么”“向量 payload 长什么样”这类问题，直接打开网页看最快。Adminer 足够轻量，Qdrant 新版本身带 Dashboard，所以不需要再引入重型工具。

## 原理

### Adminer

Adminer 是单文件 PHP 数据库管理工具，通过浏览器连接数据库服务。它在 compose 里只做了端口映射和 `depends_on`，数据库连接信息由用户在登录页填写。

### Qdrant Dashboard

Qdrant 服务本身内置 Web UI，`/dashboard` 直接读取同一容器内的集合数据，能看：

- `document_vectors`：文档切片向量。
- `memory_vectors`：阶段 4 的记忆向量。
- 每个点的 `payload`（原文、doc_id、user_id）。

## 命令解释

```powershell
docker compose up -d
```

启动全部服务（包括 adminer）。

```powershell
Invoke-RestMethod http://localhost:6333/collections
```

用 API 快速看集合列表，效果等同 Dashboard 首页。

## Adminer 登录参数

| 字段 | 值 |
|------|-----|
| 系统 | PostgreSQL |
| 服务器 | `postgres` |
| 用户名 | `aigc_user` |
| 密码 | `.env` 里的 `POSTGRES_PASSWORD` |
| 数据库 | `aigc_chat` |

## 避坑

- Adminer 的“服务器”要填 compose 服务名 `postgres`，不是 `localhost`。
- Qdrant Dashboard 是内置于 Qdrant 容器的，不要在 Docker Hub 上找单独的 `qdrant/dashboard` 镜像（本机镜像源也不稳定）。
- 这些工具只用于本地开发查看，生产环境不要直接暴露公网。
