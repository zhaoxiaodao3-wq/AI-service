# 01 · 长期记忆原理与双层记忆架构

## 做了什么

阶段 4 实现 AI 长期记忆：每轮对话结束后把“用户问题 + AI 回答”向量化存入 Qdrant `memory_vectors`；用户新提问时自动检索历史记忆，再与短期会话上下文、知识库片段一起注入 Prompt。

## 为什么

LLM 本身没有记忆，每次请求只看到当前 Prompt。阶段 1 的短期记忆靠“把当前会话历史拼进上下文”，但换会话、隔天提问就全忘了。长期记忆把关键对话转成向量存起来，用相似度检索“想起来”，突破上下文窗口限制。

## 原理

### 双层记忆

```text
最终 Prompt =
  长期向量记忆（跨会话，Qdrant 检索）
  + 短期上下文（当前会话历史消息）
  + 知识库片段（可选，use_rag）
  + 用户新问题
```

- **短期记忆**：随请求携带的 messages，解决“本会话连续对话”。
- **长期记忆**：向量化历史对话，解决“跨会话、跨时间”。

### 记忆生命周期

```text
对话结束 → 生成记忆文本 → Embedding → upsert memory_vectors
新提问 → Embedding 问题 → search_memories → 注入 Prompt → 回答
```

## 命令解释

```powershell
Invoke-RestMethod -Uri http://localhost:6333/collections/memory_vectors
```

查看记忆集合的向量数量。

## 避坑

- 记忆是“向量语义”召回，不是 SQL 精确匹配；问题表述变化但意思相近也能召回。
- 不要依赖长期记忆做精确事实查询，重要信息建议同时写入知识库。
- 记忆阈值太低会把无关历史也塞进 Prompt，干扰回答。
