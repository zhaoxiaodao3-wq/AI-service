# 04 · 记忆与知识库融合实测

## 做了什么

开启 `use_rag` 时，Prompt 会同时包含：

```text
历史记忆（跨会话）：
[记忆1] 用户：我的名字是小明 AI：好的，小明...

知识库资料：
[片段1] 苹果是红色的...

[用户] 新问题
```

长期记忆、短期上下文、知识库三者同时生效。

## 为什么

知识库回答“客观资料”，长期记忆回答“你是谁/你以前说过什么”，两者互补。实测链路：

1. 会话 A 告诉 AI“我叫小明”。
2. 上传知识库文档“苹果是红色的”。
3. 会话 B 开启知识库问“我叫什么名字 + 苹果是什么颜色”，AI 应同时利用记忆和文档回答。

## 原理

`chat_service.stream_chat_events` 合并两路检索：

```python
if use_rag:
    hits = vector_repo.search_documents(...)
if session_id is not None:
    memories = vector_repo.search_memories(..., exclude_session_id=session_id)
safe_messages = build_rag_messages(safe_messages, hits=hits or None, memories=memories or None)
```

`build_rag_messages` 把两类片段分别标记为“历史记忆”和“知识库资料”，防止模型混淆来源。

## 命令解释

```powershell
$body = '{"messages":[{"role":"user","content":"我叫什么名字？苹果是什么颜色？"}],"model":"glm-4-flash","session_id":7,"use_rag":true}'
Invoke-RestMethod -Uri http://localhost:8000/api/chat/stream -Method Post -ContentType "application/json" -Body $body
```

同时开启记忆与知识库的流式提问。

## 避坑

- 知识库没有内容时检索为空，回答只会依赖记忆。
- 记忆没有内容时检索为空，回答只会依赖知识库。
- 两类检索任一失败都不应中断聊天：知识库失败目前会报错，记忆写入失败已做 warning 兜底；后续阶段可统一容错。
