# 03 · 项目收尾与运维清单

## 做了什么

项目进入收尾状态：

- 前端、后端、PostgreSQL、Qdrant、观测栈、Adminer 全部容器化。
- 一键启动、健康检查、README 架构/功能/端口齐全。
- 所有阶段学习文档完整归档。

## 功能清单（最终成品）

- 多模型统一适配，官方/中转双模式，模型配置化
- SSE 流式对话 + 打字机效果
- 会话/消息/文档/模型配置全持久化
- 文档上传 + 手写 RAG 知识库问答
- AI 长期向量记忆（跨会话召回）
- 聊天限流、流式重试、调用统计
- Loki + Grafana 实时日志观测
- Adminer / Qdrant Dashboard 可视化

## 运维清单

### 每天

- `docker compose ps`：确认服务健康。
- Grafana：查看后端日志是否有 `error`。

### 上线前

- 更换 `SECRET_KEY`、数据库密码、API Key。
- 生产数据库改用云托管，不用容器 PostgreSQL。
- 前端/后端加 HTTPS 与域名。
- Loki 配置保留期，防止磁盘打满。
- 多实例部署时，把限流/统计换成 Redis 共享方案。

## 命令解释

```powershell
docker compose up -d --build
docker compose logs -f backend
docker compose ps
```

## 避坑

- 容器 PostgreSQL 只适合开发；生产用云数据库 + 备份。
- `create_all` 建表不适合生产，后续引入 Alembic。
- 所有 Key 必须走环境变量/Secret 管理，不能进镜像和 git。
