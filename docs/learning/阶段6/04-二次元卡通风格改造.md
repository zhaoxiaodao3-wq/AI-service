# 04 · 二次元卡通风格改造

## 做了什么

调用 ui-ux-pro-max 技能生成设计系统后，把前端改为二次元卡通风：

- 玫瑰红 `#E11D48` + 糖果粉 `#FB7185` + 天蓝 `#2563EB` + 薄荷/奶油底。
- Claymorphism 软糖风格：3px 厚边框、16-22px 圆角、内外双层阴影。
- 全局圆点奶油背景、Fredoka/Nunito 字体。
- 顶栏、首页、聊天页、上传页统一卡通化。

## 为什么

项目是面向个人的 AI 聊天产品，用户希望“好看、有性格”。卡通风比默认 Element Plus 更有辨识度，且用 CSS token 实现，后续可以统一改主题。

## 原理

### 设计 token

```css
:root {
  --color-primary: #e11d48;
  --color-secondary: #fb7185;
  --color-accent: #2563eb;
  --color-border: #fecdd3;
  --shadow-outer: 5px 5px 0 rgba(225, 29, 72, 0.16);
}
```

所有组件只引用语义变量，不写散落色值。

### 双层阴影

Claymorphism 的关键是“软糖立体感”：

```css
box-shadow: var(--shadow-outer), var(--shadow-inner);
```

外层投影 + 内层高光，让按钮/气泡像可以按下去的软糖。

## 命令解释

```powershell
cd frontend
pnpm build
docker compose up -d --build frontend
```

构建并发布卡通版前端到 http://localhost:5173。

## 避坑

- 文字对比度要保持：深玫瑰 `#881337` 在奶油底上可读，避免用浅粉配白字。
- 动效控制在 150-300ms，并尊重 `prefers-reduced-motion`。
- 不要用 emoji 当图标，继续使用 Element Plus 图标库。
- 卡通化只在 CSS 层完成，功能逻辑零改动。
