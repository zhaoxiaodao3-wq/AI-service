# 02 · 密码安全与刷新令牌

## 做了什么

密码使用 bcrypt 哈希存储，登录校验用 `bcrypt.checkpw`；登录成功后返回：

- `access_token`（短期，默认 60 分钟）
- `refresh_token`（长期，默认 7 天，数据库只存哈希）

支持刷新与登出：

- `POST /api/auth/refresh`：旧 refresh 撤销并轮换新令牌对。
- `POST /api/auth/logout`：撤销 refresh token。

## 为什么

访问令牌过期时间短，降低泄露风险；刷新令牌不落明文（只存 SHA-256 哈希），即使数据库泄露也不能直接使用。

## 原理

### bcrypt

```python
hash = bcrypt.hashpw(password.encode(), bcrypt.gensalt())
bcrypt.checkpw(password.encode(), hash)
```

自动加盐，撞库成本高。

### 刷新令牌轮换

```text
login → 生成 refresh（原文给前端，库存哈希）
refresh → 校验哈希 + 未撤销 + 未过期 → 撤销旧 token → 生成新令牌对
logout → 标记 revoked
```

## 命令解释

```powershell
Invoke-RestMethod -Uri http://localhost:8000/api/auth/refresh -Method Post -ContentType "application/json" -Body '{"refresh_token":"..."}'
```

刷新后旧 refresh 立即失效。

## 避坑

- 刷新令牌必须轮换，否则泄露后一直可用。
- 登出必须撤销服务端记录，只清前端没用。
- 不要把 refresh token 暴露给前端之外的服务。
