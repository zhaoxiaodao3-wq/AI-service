# 04 · 前端登录与路由守卫

## 做了什么

前端新增：

- `/login` 登录/注册页。
- 路由守卫：未登录访问业务页跳登录。
- `request.ts` 自动携带 Token；401 自动清理并跳登录。
- 顶栏显示用户名与退出按钮。

## 为什么

后端已经有认证，前端需要把登录态接起来，否则用户无法使用业务功能。

## 原理

### 路由守卫

```ts
router.beforeEach((to) => {
  const token = localStorage.getItem('access_token')
  if (to.path !== '/login' && !token) return { path: '/login' }
  return true
})
```

### 请求拦截

```ts
request.interceptors.request.use((config) => {
  const token = localStorage.getItem('access_token')
  if (token) config.headers.Authorization = `Bearer ${token}`
  return config
})
```

## 命令解释

```powershell
cd frontend
pnpm build
docker compose up -d --build frontend
```

访问 http://localhost:5173 会先到登录页。

## 避坑

- 401 处理要排除 `/auth/login` 和 `/auth/register`，否则登录接口也会被踢。
- 生产建议用 HttpOnly Cookie 而不是 localStorage，降低 XSS 风险。
- 退出时要调后端撤销 refresh token，不能只清前端。
