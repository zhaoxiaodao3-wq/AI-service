## 阶段 7：用户认证与多租户

### 原始需求

1. 用户注册、登录、退出。
2. 密码使用安全哈希存储（bcrypt/argon2）。
3. JWT 登录态，支持过期与刷新。
4. 会话、消息、文档、模型配置、记忆全部按 `user_id` 隔离。
5. 前端登录页、路由守卫、请求自动携带 Token。
6. 旧 `local` 用户数据迁移到真实用户。

### 核心任务

- `auth` API（register/login/logout/refresh/me）。
- FastAPI 依赖 `get_current_user` + 全局用户上下文。
- 所有业务查询/写入从“默认用户”改为“当前用户”。
- 前端登录页与 `request.ts` 拦截器。

### 验收标准

- 两个用户互不可见会话/文档/记忆。
- 未登录访问业务接口返回 401。
- Token 过期后前端自动跳登录。

## 阶段 8：Agent 工具调用

### 原始需求

1. 工具注册中心：名称、描述、JSON Schema 参数。
2. 模型 Function Calling 循环：请求带工具 → 模型选工具 → 执行 → 结果回填 → 继续生成。
3. 内置工具：当前时间、计算器、知识库检索、只读数据库查询、（可选）网页搜索。
4. 前端展示“正在调用工具”与调用过程。
5. 工具调用日志进入 Loki/Grafana；失败有兜底。

### 核心任务

- `tools/registry.py`、`tools/base.py`、内置工具实现。
- 适配层支持 `tools` 参数与多轮 tool message。
- 前端工具调用事件（SSE `tool_start/tool_done`）。

### 验收标准

- 模型能自主选择工具并基于结果回答。
- 工具调用过程可见、可追踪。
- 恶意工具参数不破坏系统。

## 阶段 9：RAG 增强（Rerank + 混合检索 + 引用溯源）

### 原始需求

1. 混合检索：BM25/关键词 + 向量检索，RRF 融合。
2. Rerank 精排：TopK 后再用 rerank 模型排序。
3. 引用溯源：回答内容关联文档片段，返回 `doc_id/chunk_index`。
4. 前端展示引用，可跳转到对应文档/片段。
5. 支持 embedding 模型/维度变更后的重新向量化。

### 核心任务

- 关键词索引（PostgreSQL FTS/trigram 或独立 BM25 实现）。
- `retrieval` 服务：向量 + 关键词 → RRF → Rerank。
- SSE 事件携带 citations；前端渲染引用卡片。

### 验收标准

- 混合检索召回优于纯向量。
- 回答引用可溯源到原文片段。
- Rerank 后 TopK 相关性明显提升。

## 阶段 10：异步任务与文件处理

### 原始需求

1. Redis + RQ/ARQ 任务队列。
2. 文档上传改为异步：解析 → 切片 → 向量化 → 入库。
3. 任务状态/进度 API，前端轮询或 SSE 展示。
4. 失败自动重试，支持批量导入与增量更新。
5. 独立 worker 容器。

### 核心任务

- `tasks/document_tasks.py`、`tasks/worker.py`。
- `documents` 表增加任务状态字段。
- 前端上传页显示“解析中/向量化中/完成/失败”。

### 验收标准

- 大文档上传不阻塞聊天接口。
- 任务失败可重试，进度可见。

## 阶段 11：缓存、分布式限流与安全

### 原始需求

1. Redis 缓存：模型响应缓存（语义命中）、热点会话/文档缓存。
2. 分布式限流：按 IP + 用户维度，多实例共享。
3. Prompt Injection 防护：输入检测、工具参数校验。
4. SSRF 防护：工具/爬虫类 URL 校验。
5. API Key 轮换与过期管理。

### 核心任务

- Redis 客户端与缓存服务。
- 限流中间件改为 Redis 滑动窗口。
- 安全过滤器与输入审计。

### 验收标准

- 多实例共享限流计数。
- 缓存命中不重复调用模型。
- 注入/SSRF 样例被拦截并记录。

## 阶段 12：可观测性与工程化部署

### 原始需求

1. Alembic 迁移替代 `create_all`，支持表结构升级。
2. OpenTelemetry 全链路 Trace：HTTP → RAG → LLM → PG/Qdrant → 工具。
3. Trace 接入 Grafana Tempo/Loki，与日志关联。
4. CI/CD：测试 → 构建 → 镜像推送 → 部署。
5. 生产部署文档：云数据库、HTTPS、备份恢复、资源限制。

### 核心任务

- Alembic 初始化与迁移版本。
- OTel instrumentation（FastAPI/SQLAlchemy/Qdrant/litellm）。
- GitHub Actions 或自建流水线。

### 验收标准

- 数据库可迁移升级。
- 一次请求能看到完整 Trace 瀑布。
- CI 全绿可一键部署。

## 阶段 13：产品化体验

### 原始需求

1. 语音输入与语音回答（Web Speech / STT+TTS 可切换）。
2. 会话分享与导出（Markdown/PDF）。
3. 文档在线预览与引用片段跳转。
4. PWA / 移动端优化（安全区、触控、离线提示）。

### 核心任务

- 前端语音组件、导出工具。
- 引用跳转与文档预览。
- manifest + service worker。

### 验收标准

- 语音可用、导出可读、引用可跳转。
- 移动端无溢出、触控友好。
