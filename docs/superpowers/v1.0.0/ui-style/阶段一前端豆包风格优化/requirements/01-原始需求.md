# 阶段一补充：前端页面 UI 优化（参照豆包网页版）

## 原始需求

用户反馈阶段一前端页面太丑，要求参照豆包网页版（`www.doubao.com/chat` 公开界面风格）整体优化视觉与交互：

1. 聊天页：左侧会话栏 + 居中对话流 + 底部圆角输入区的现代浅色布局，消息气泡、模型选择、附件展示、错误/加载状态都要好看。
2. 全局：首页、文档上传页、顶部导航与整体配色同步优化，消除默认 Element Plus 粗糙观感。
3. 保持现有功能不变：流式对话、模型下拉、会话切换、附件上传、错误提示等全部可用。

## 参考

- 豆包网页版公开界面：浅色背景、左侧会话列表、居中窄栏对话流、底部圆角输入区、图标化操作按钮。
