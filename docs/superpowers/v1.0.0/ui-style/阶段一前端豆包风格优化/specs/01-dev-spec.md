# 阶段一前端豆包风格优化 · 开发规格

**Requirement:** [../requirements/01-原始需求.md](../requirements/01-原始需求.md)

## 背景与目标

阶段一功能已完成，但页面仍以默认 Element Plus 组件外观为主，视觉粗糙。本规格参照豆包网页版的公开界面气质（浅色、干净、居中对话流、图标化操作），在**不改变现有功能**的前提下重做前端视觉，覆盖聊天页、首页、上传页与顶部导航。

## 方案选型

- 推荐：纯 Vue 组件 + scoped CSS 重构，不引入新的 UI 框架；Element Plus 继续承担表单/弹层能力。
- 备选：引入 Tailwind 或 Naive UI。成本高、收益低，本阶段不采用。
- 风格参考为豆包网页版公开观感，非 Figma 像素级还原。

## 设计

### 1. 全局视觉

- 页面背景：`#F5F6F7`；主文字：`#1F2329`；次要文字：`#86909C`。
- 品牌强调色：`#4E6EF2`（hover `#3B5CE8`），不采用大面积紫蓝渐变。
- 白色内容层、8px 圆角卡片、1px `#E5E6EB` 边框。
- `style.css` 统一字体栈、滚动条样式与 Element Plus 按钮/输入框微调。

### 2. 顶部导航（MainLayout）

- 56px 白色顶栏，左侧品牌区（渐变方形 logo + “AIGC 对话平台”），右侧导航菜单。
- 首页/聊天/文档上传三个入口保持可用，当前路由高亮。

### 3. 聊天页（ChatView）

- 左侧栏 240px 白底：品牌区、通栏“新对话”按钮、会话列表。
- 主区顶部 56px 白底 header：左侧会话标题，右侧模型下拉。
- 消息区居中，内容最大宽度 760px：
  - 用户消息右对齐，浅蓝气泡 `#EEF3FF`，圆角 10px。
  - AI 消息左侧 32px 圆角方形头像（品牌渐变 + 图标），正文白底无边框。
  - 附件图片以 96px 圆角缩略图展示，文件以 chip 展示。
- 加载中：AI 头像旁“三点呼吸”动画，不使用闪烁文字。
- 空态：居中“今天想聊点什么？”与品牌图标，无操作说明文字。
- 错误态：`[错误 code] message` 显示在红色提示条内。
- 输入区：底部居中，最大宽度 760px，白色 12px 圆角容器：
  - 左侧附件/图片圆形图标按钮（带 tooltip），文本域自适应 1-5 行，Enter 发送，Shift+Enter 换行。
  - 右侧圆形发送按钮（`Promotion` 图标），空内容禁用。
- 响应式：`<=768px` 侧栏收窄为 64px（只显示品牌与会话首字圆标），主区不换行溢出。

### 4. 首页（HomeView）

- 居中产品首屏：品牌 logo、标题、一行副标题、两个入口按钮。
- 无大段营销文案，不做浮夸 hero 图。

### 5. 文档上传页（UploadView）

- 居中虚线框占位：上传图标 + “文档上传将在阶段 3 接入”，与全局浅色风格一致。

## 样式对照（豆包网页版）

> 参考豆包网页版公开界面观感，非像素级还原；本表用于锁定本实现的关键 token。

| 项目 | 豆包网页版参考 | 本实现 |
|------|----------------|--------|
| 页面背景 | 浅中性灰白 | `#F5F6F7` |
| 内容/侧栏底色 | 白色 | `#FFFFFF` |
| 主强调色 | 品牌蓝（约 `#4E6EF2` 系） | `#4E6EF2` |
| 主文字 | 深灰黑 | `#1F2329`，15px |
| 次要文字 | 中灰 | `#86909C`，13px |
| 间距 | 16-24px 节奏 | 16px/24px |
| 圆角 | 会话项 6-8px，输入区约 12px | 6-8px / 12px |
| 消息区宽度 | 窄栏居中（约 760px） | max-width 760px |
| 输入区 | 底部圆角白色容器 + 图标按钮 | 同左，12px 圆角 |
| 用户消息 | 浅蓝气泡 | `#EEF3FF` |

## 验收标准

- [x] 聊天页完成豆包风格浅色布局，左栏/头部/消息流/输入区层次清晰。
- [x] 流式对话、模型下拉、会话切换、附件上传、错误提示功能全部保持可用。
- [x] 首页、上传页、顶部导航视觉同步优化，无默认 Element Plus 粗糙观感。
- [x] 移动端（<=768px）侧栏收窄后无文字溢出或布局错乱。
- [x] `pnpm build` 通过；Edge headless 截图检查桌面/移动端无重叠。

## 非目标

- 不改后端接口与数据结构。
- 不做多模态图片理解、不做会话持久化（阶段 2）。
