# 阶段六补充：聊天布局交互优化修订

## 原始需求

用户反馈上一版聊天布局改动不合理、质量差，并要求用 ui-ux-pro-max 重新审查。审查结论：

1. “输入框居中”用 `transform: translateY(calc(-50vh + 80px))` 硬编码位移实现，脆弱、违背聊天产品“输入区固定底部”的常规认知。
2. “今天想聊点什么？”放在输入区上方位置不合理，应作为消息区空态居中展示。
3. 回底按钮阈值固定且绝对定位可能遮挡内容。
4. 侧栏整高滚动应使用标准 flex + min-height 方案，避免硬编码高度。

## 修订目标

1. 输入框始终固定在聊天区底部；空会话时“今天想聊点什么？”居中显示在消息区。
2. 侧栏占满整高，会话多时只在侧栏内部滚动。
3. 消息区独立滚动；只要不在底部就显示回底按钮，点击平滑回底。
4. 尊重 `prefers-reduced-motion`，补齐无障碍标签。
