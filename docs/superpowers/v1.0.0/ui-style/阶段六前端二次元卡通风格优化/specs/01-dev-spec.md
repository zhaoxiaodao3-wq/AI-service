## 页面要求

### 全局（style.css）

- 引入 Fredoka/Nunito。
- 定义语义色变量。
- 背景为奶油粉 + 细圆点纹理。
- Element Plus 按钮/输入框统一卡通圆角与厚边框。

### 顶栏（MainLayout）

- 白色表面 + 3px 边框。
- 品牌 logo 渐变圆角方块。
- 导航为药丸按钮，active 用玫瑰色。

### 首页（HomeView）

- 大号渐变 logo + 卡通标题。
- 按钮带厚边框与双层阴影。

### 聊天页（ChatView）

- 左侧栏白底圆角卡片，新对话按钮玫瑰渐变。
- 用户气泡浅粉，AI 气泡白底厚边框。
- 输入区白色圆角容器，发送按钮圆形渐变。
- 保留打字机光标、加载动画、附件样式，全部改为卡通色。

### 上传页（UploadView）

- 虚线厚边框上传盒，图标圆底。
- 文档列表改为软糖卡片。

## 验收标准

- [x] 首页/聊天页/上传页/顶栏统一二次元卡通风格。
- [x] 功能（流式对话、会话、上传、删除、知识库开关）保持不变。
- [x] `pnpm build` 通过。
- [x] 桌面与移动端截图无溢出、无重叠。
- [x] 学习文档已新增。

## 非目标

- 不改后端接口与功能逻辑。
- 不引入图片素材（纯 CSS 卡通化）。
