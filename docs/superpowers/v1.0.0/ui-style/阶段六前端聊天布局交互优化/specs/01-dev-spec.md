# 阶段六前端聊天布局交互优化 · 开发规格

**Requirement:** [../requirements/01-原始需求.md](../requirements/01-原始需求.md)

## 背景与目标

当前侧栏会话区在内容多时可能撑破布局；新会话输入框固定在底部，缺少“中央输入 → 发送后落到底部”的对话式体验；消息滚动缺少快速回底按钮。本模块修复这三处交互。

## 设计

### 1. 侧栏整高滚动

- `.chat-page` 高度 100%，`overflow: hidden`。
- `.sidebar` 高度 100%，`min-height: 0`，内部 `session-list` 使用 `overflow-y: auto`。
- 品牌区/新对话按钮固定，只有会话列表滚动。

### 2. 输入框居中 → 落底动画

- `ChatView` 增加 `centeredInput` 计算属性：当前会话无消息且未在加载时启用。
- 居中态：隐藏消息区，输入区使用 `transform: translateY(calc(-50vh + 80px))` 上移到屏幕中央，过渡 350ms。
- 发送第一条消息后类移除，输入区平滑回到底部固定位置。
- 居中态输入区上方显示“今天想聊点什么？”。

### 3. 消息区滚动与回底按钮

- `.messages` 保持 `flex:1; overflow-y:auto; min-height:0`，增加底部 padding 防止被输入区遮挡。
- 监听 `scroll`：距离底部超过 160px 且消息数 >= 4 时显示“回到底部”按钮。
- 按钮点击平滑滚动到底部，滚到底后按钮隐藏。

## 验收标准

- [x] 侧栏占满整高，会话多时只在侧栏内滚动。
- [x] 新会话输入框居中；发送后动画落到底部。
- [x] 消息多时只有聊天区滚动，整页不滚动。
- [x] 消息多且未在底部时出现回底按钮，点击平滑回底并隐藏。
- [x] `pnpm build` 通过，桌面/移动端截图无溢出。

## 非目标

- 不改后端。
- 不改打字机/流式逻辑。
