# 阶段五：工程化完善与双模式兼容

## 原始需求

按全阶段手册阶段 5 要求完善稳定性、安全性与统计能力：

1. 模型配置化：每个模型在 `ai_models` 表管理自己的 provider/API Key/BaseURL，聊天按所选模型读取配置，未配置时回退 `.env`。
2. 双模式兼容：官方直连与第三方中转仍可一键切换；中转 SSE 断流时自动重试。
3. 安全与容错：聊天接口限流，防止刷接口；流式调用失败自动重试。
4. 数据统计：记录每次模型调用的 Token 消耗、模型、会话、成功率、耗时，提供统计接口。
5. 日志与观测：沿用 Loki/Grafana；补充统计与运维建议。
6. 学习文档。
