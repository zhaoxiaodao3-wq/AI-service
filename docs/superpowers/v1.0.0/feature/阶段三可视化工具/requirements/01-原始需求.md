# 阶段三补充：数据库与向量库可视化工具

## 原始需求

用户希望用网页界面可视化查看 PostgreSQL 业务表和 Qdrant 向量库：

1. PostgreSQL：提供轻量网页管理工具（Adminer），可查看 users/ai_models/chat_sessions/chat_messages/documents 等表。
2. Qdrant：使用 Qdrant 自带 Dashboard，查看 document_vectors/memory_vectors 集合、向量数量与 payload 原文。
3. 工具随 `docker compose up -d` 一键启动，不单独打命令。
4. 提供连接参数与使用说明。
