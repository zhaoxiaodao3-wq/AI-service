## 改动摘要

用户反馈 SSE 内容其实已经返回，但页面仍停在加载动画，且没有打字机效果。本次把“等待中”和“展示中”拆开：第一个 `delta` 到达立即隐藏加载动画，并把分片放入缓冲区，由定时器按打字机节奏逐段追加；流结束/错误时立即补全。

## 遗留风险

- 打字速度固定为每 20ms 显示 2 个字符，未做成可配置；后续需要可在设置中调整。
- 打字机节奏较慢时，长回答需要一段时间显示完；流结束会立即补全，不会丢内容。
