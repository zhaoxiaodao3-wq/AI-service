# 阶段一补充：实时日志观测平台（Loki + Grafana）

## 原始需求

用户不满足于命令行 `docker logs`，希望用主流的**实时日志观测软件**观察后端请求/响应日志：

1. 不要写日志文件，日志必须从容器 stdout 实时采集。
2. 提供浏览器网页界面，打开后能像终端 `tail -f` 一样实时滚动查看日志。
3. 接入成本低、适合本地练手项目，全部跑在 Docker Compose 里。
4. 能按容器/服务过滤日志，例如只看 `aigc-backend`。
5. 保留现有 `docker compose logs` 与本地 uvicorn 终端日志能力，作为补充而不是替代。

## 推荐方案

采用 **Grafana Loki + Promtail + Grafana**：

- Promtail：实时尾随 Docker 容器 stdout，推送到 Loki，不落盘。
- Loki：轻量日志存储与索引。
- Grafana：Web 界面，Explore + Live Tail 实时观测。
