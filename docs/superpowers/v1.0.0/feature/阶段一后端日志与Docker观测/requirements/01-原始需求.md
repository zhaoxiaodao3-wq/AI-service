# 阶段一补充：后端请求/响应日志与 Docker 日志查看

## 原始需求

用户问：能否通过 Docker 客户端查看日志，例如前端发了消息给后端时能看到请求，以及后端返回了什么。

要求：

1. 后端对每个 HTTP 请求记录日志：方法、路径、客户端 IP、请求体摘要（聊天消息数量/模型/内容预览）。
2. 对 SSE 流式对话记录完整过程：开始、事件统计、结束时的状态/耗时/返回字符数/内容预览，错误时记录错误码。
3. 后端服务加入 Docker Compose，使 `docker compose logs backend`（或 Docker Desktop 图形界面）能看到上述日志。
4. 输出一份学习文档，教用户用 Docker 客户端查看日志并理解请求/响应链路。
5. 不改变现有接口行为与本地开发启动方式。
