# 阶段三：自建 Qdrant + 完整 RAG 知识库

## 原始需求

按照全阶段手册阶段 3 的要求，手写完整 RAG 链路，不依赖黑盒框架：

1. 前端支持 PDF/TXT/MD 文件上传；后端接收文件，文件元信息保存到 PostgreSQL。
2. 文档解析：PDF 使用解析库，TXT/MD 直接读文本。
3. 文本切片：手动实现 chunk_size 与 chunk_overlap，理解切片原理。
4. Embedding 向量化：调用 Embedding 模型 API，把切片转成向量。
5. 手动编写 Qdrant 入库逻辑：存向量、原文、文档 ID、用户 ID。
6. 自研相似度检索：问题向量化 → Qdrant 检索 → TopK + 相似度阈值过滤。
7. RAG Prompt 组装：系统提示词 + 检索片段 + 用户问题 → 大模型流式回答。
8. 聊天页提供“知识库问答”开关，开启后使用 RAG 链路。
9. 每个步骤提供学习文档（做了什么/为什么/原理/命令解释/避坑）。
